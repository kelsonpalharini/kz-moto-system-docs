# KZ Moto System brand assets

Published with the API docs at `https://kelsonpalharini.github.io/kz-moto-system-docs/brand/` and
used by the web frontend on the platform pages (no workshop slug). Extracted from the brand kit.

| File | Use |
|---|---|
| `kz-moto-logo.png` | Full logo (KZ + MOTO SYSTEM), transparent background |
| `kz-mark.png` | "KZ" mark only, transparent background |
| `kz-icon.png`, `kz-favicon-48.png` | App icon and favicon |
| `kz-hero.jpg` | Sign-in page image |

Palette: orange `#F75217`, charcoal `#1E1F20`, graphite `#3D3E40`, silver `#D8D8D8`, background
`#0B0B0C`. Typeface: Montserrat.

Workshops do not use these files: their logo, icon and colours come from their own brand settings
(`/tenants/{id}/branding`).
