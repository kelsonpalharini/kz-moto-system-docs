# Oficinas piloto

Dados e marca das oficinas que participam do piloto do KZ Moto System. Publicado com a
documentação da API em `https://kelsonpalharini.github.io/kz-moto-system-docs/piloto/`; as URLs
dos logos são usadas na configuração de marca de cada oficina (`PUT /tenants/{id}/branding`).

|---|---|---|
